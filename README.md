Замены произведены скриптами:

- [scripts/build_terms_map.py](scripts/build_terms_map.py) строит словарь замен (детерминированный генератор выдуманных имён с зерном 42);

## Задание 3. Создание векторного индекса

Модель:

- Название: BAAI/bge-m3
- Ссылка на репозиторий / API: <https://huggingface.co/BAAI/bge-m3>
- Размер эмбеддингов: 1024, нормализованные

Размер чанков: 1800 символов (около 300 слов), перекрытие 200 символов. Документы режутся на чанки по секциям до заголовка `##`, крупные секции режутся по абзацам и предложениям. Использован `RecursiveCharacterTextSplitter` из пакета `langchain-text-splitters` с сепараторами `["\n## ", "\n\n", ". ", " ", ""]` и `keep_separator=True`. У каждого чанка есть префикс -- заголовок документа.

Метаданные (хранятся в `meta.json` рядом с каждым чанком):

- `id` -- глобальный номер чанка; совпадает с номером строки в FAISS-индексе;
- `source` -- путь к файлу базы знаний; по нему можно цитировать документ;
- `title` -- заголовок страницы из front-matter; по нему можно назвать источник в ответе;
- `chunk` -- позиция чанка внутри документа; по ней можно восстановить порядок фрагментов одного документа;
- `entities` -- термины сущностей страницы из front-matter; по ним можно фильтровать поиск по сущности и связывать чанки одного существа из разных документов;
- `text` -- полный текст чанка (вместе с префиксом-заголовком); можно не перечитывать исходные документы.

Кроме метаданных, в `meta.json` записаны модель, размерность, параметры чанкинга и время генерации эмбеддингов.

Файл индекса: [vector_store/faiss.index](vector_store/faiss.index) (IndexFlatIP) + [vector_store/meta.json](vector_store/meta.json).

Индекс создан скриптом [scripts/build_index.py](scripts/build_index.py) (эмбеддинги кэшируются в `scripts/data/cache/`).

Время генерации: 270 с (298 чанков, 1.10 чанка/с; повторный запуск берёт чанки из кэша).

Примеры запросов к индексу (результат `python scripts/build_index.py --test`):

1. Запрос: "Which spirit applies the Weakness status effect?" -> Чанки: `001_ostrek_ulkoth.md` чанки 0 (0.546) и 1 (0.519) -- документ духов и их статусных эффектов, далее победители боссов (0.470 и ниже); верный документ с большим отрывом.
2. Запрос: "Where does the shielded flying drone spawn?" -> Чанки: `060_naktoi_krelkoth.md` чанк 0 (0.581) -- вторая позиция; первая (0.584) -- `136_sarnel_vosqir.md`, тоже летающий робот-дрон с щитом из того же биома, семантически близкий конкурент.
3. Запрос: "Какой дух накладывает эффект берсерк?" -> Чанки: те же `001_ostrek_ulkoth.md` чанки 0 (0.548) и 1 (0.533) -- кросс-язычный поиск работает: вопрос на русском находит документ на английском.

## Задание 4. Реализация RAG-бота с техниками промптинга

Исходник: [scripts/rag_bot.py](scripts/rag_bot.py) -- консольный REPL-бот (режим `--ask "вопрос"` задаёт один вопрос и выходит).

Пайплайн:

1. Запрос кодируется той же моделью bge-m3, что и чанки индекса (нормализованные эмбеддинги).
2. FAISS IndexFlatIP ищет top-5 чанков; score -- косинусная близость. Чанки с близостью ниже 0.40 отбрасываются; если ничего не осталось -- бот отвечает «Я не знаю», не тратя вызов LLM.
3. Собирается промпт: системный промпт + примеры Few-shot + найденные чанки с номерами и источниками.
4. Ответ генерирует LLM -- любой OpenAI-совместимый провайдер, конфигурация только через переменные окружения: `OPENAI_API_KEY` (ключ), `OPENAI_BASE_URL` (адрес провайдера; по умолчанию официальный OpenAI), `RAG_CHAT_MODEL` (имя модели; по умолчанию `gpt-6-luna`).

Техники промптинга:

- **Few-shot** -- после системного промпта добавляются две пары сообщений «вопрос -> ответ» из документа `001_ostrek_ulkoth.md`: первая задаёт формат успешного ответа (шаги рассуждения, ответ, источник в квадратных скобках), вторая -- формат отказа.
- **Chain-of-Thought** -- системный промпт требует 1-3 шага рассуждения до итогового ответа.
- **Grounding** -- системный промпт требует отвечать строго по найденным фрагментам, не опираясь на память о похожих вселенных.
- **Refusal** -- системный промпт требует при недостатке данных в фрагментах отвечать точной фразой «Я не знаю -- в базе знаний нет данных по этому вопросу».

Так же системный промпт требует отвечать на языке вопроса (RU-вопрос по EN-чанкам базы отвечает по-русски).

Примеры 3-5 успешных диалогов:

1. Q: «Какой дух накладывает эффект берсерк?» -> A: «Эффект Berserk накладывает дух Zentha Nakqir, известный также как Nakqir Warden [001_ostrek_ulkoth.md, чанк 0]».
2. Q: «Что будет, если бить Ostrek Ulsha из быстрой палочки с малым уроном?» -> A: «Ostrek Ulsha будет выпускать луч за каждый тик полученного урона. При быстрой стрельбе с малым уроном лучи могут за считаные секунды истощить даже большой запас здоровья, а щиты дадут мало защиты [021_ostrek_ulsha.md, чанк 1]».
